### Homework 5: Neural Networks & Deep Learning (MATLAB)
[Homework 5](./hw5/)

This folder contains two parts comparing classical ANN and deep learning approaches for bird/cat/dog image classification using MATLAB.

| Part | Method | Accuracy |
|------|--------|----------|

| [Part 2](./hw5/part2/) | Transfer Learning with SqueezeNet (CNN) | ~94% |

Dataset: [Bird/Cat/Dog 13,000 images](https://www.kaggle.com/datasets/mahmoudnoor/high-resolution-catdogbird-image-dataset-13000)
